# ALS online

空・陸・海の3戦域をめぐる、2人用カードゲームの非公式ブラウザ実装です。HTML・CSS・JavaScriptだけで動き、アプリやゲームエンジンのインストールは不要です。

## 遊ぶ

GitHub Pagesが有効なら、次のURLをSafariやChromeで開くだけで遊べます。

https://akaisotaro.github.io/als_online/

- 「オンライン部屋を作る」: 表示された2桁の数字の招待コードまたは招待URLを相手へ送ります。
- 招待された側: コードを入力して「参加」を押します。

オンライン対戦では部屋を作った側が進行を管理するため、対戦中は双方ともページを開いたままにしてください。通信にはPeerJSの公開中継サービスを利用しています。長期運用や不正対策を行う場合は専用サーバーへの置き換えが必要です。

## 実装済み

- 18枚のカードと指定された日本語効果文
- 表向き／裏向き配置、被覆、戦力計算、同点時の先攻優先
- 全カード能力、撤退点、戦域ローテーション、先攻交代、12点勝利
- スマートフォン向けレスポンシブ画面
- PCのドラッグ＆ドロップ、スマホのスワイプ配置
- 招待コード式P2Pオンライン対戦
- 対戦中にも開ける `web/rule.md` 連動のルール画面
- GitHub ActionsによるGitHub Pages公開

## ルール文章の編集

`web/rule.md` を編集してGitHubへ反映すると、ゲーム内の「ルール」ポップアップも同じ内容に更新されます。カード効果文と得点処理はこのファイルにまとめています。

## ローカル確認

ES Modulesを使用しているため、ファイルを直接開かず簡易Webサーバーから開きます。

```powershell
python -m http.server 8080 --directory web
```

その後、`http://localhost:8080/` をブラウザで開きます。

## 自動テスト

Node.jsだけでブラウザ版のルールテストを実行できます。

```powershell
node tests/game.test.mjs
```

## 構成

- `web`: 公開されるゲーム本体
- `tests`: ブラウザ版のルールテスト
- `docs`: カード効果文の原資料と取り扱いメモ
- `.github/workflows`: テストとGitHub Pages公開設定

## 取り扱い

原作の画像・ロゴは収録していません。カード効果文は依頼者提供の `docs/ALS_JPcards.md` を基にしています。身内利用を想定していますが、リポジトリやGitHub Pagesを公開設定にするとURLを知る人以外からもアクセスできる可能性があります。
