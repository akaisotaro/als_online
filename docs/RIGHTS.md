# 権利と公開方針

この実装は、3戦域・18枚・撤退得点というゲームの仕組みを検証するための非公式プロジェクトです。

- 原作の商品名をアプリ名、ロゴ、ドメイン名として使用しません。
- 原作のカード画像、イラスト、ロゴ、組版、説明書画像を収録しません。
- カード名と説明文は独自の日本語表現に置き換えています。
- 原作者・出版社による承認や提携を示す表現をしません。
- 一般公開前に、対象地域の法令と権利者のガイドラインを確認してください。

ルールの事実確認には、Arcane Wondersが公開している公式ルールブックとカード補足を参照しています。これらのPDF自体はリポジトリへ再配布しません。
